Machine Learning vs. Deep Learning: Two Case Studies

Abhijeeth Reddy · AIML-500, Workshop 2 · ← Back to portfolio

Introduction

Machine learning and deep learning are the words that we often see are interchanged, but there is a significant difference between both of them. Generally ML depends on features that humans give and the ML model learns from under those specifications. Deep learning involves the process of multi layer neural networks that can learn their own representations from raw input. Our choice depends on the data available, shape of the data, cost of errors and also available compute. We will look into one case from each side.

Example 1: Spam Classification (ML)

Problem: For all the messages received, Gmail has to decide if it is spam. Examples come from users marking messages as spam or keep them, this can be considered as supervised binary classification.

Why ML? Humans can name spam signals. As this data can be shaped by feature, with one row per message logistic regression models or tree ensembles models are trained on it. We can also retrain the models with little expenses. The feature based models can be refreshed very quickly as spammers adapt constantly which they tend to do. If a message that is not supposed to be marked spam was marked as spam, the engineer can identify what feature might have fired and adjust the rule of weighing.

Why DL is not useful? The data that is useful to us is not hidden in raw data that needs layered representation learning. If the network is deep it would add compute and parameters and even with those there would not be any clear gain for the input we give. The failure due to this opacity also makes this costly which in turn makes it hard to handle.

Example 2: Self-Driving Perception (DL)

Problem: An autonomous vehicle is expected to identify humans, bicycles, vehicles, lane markings and traffic lights. And the data is input from sensors in real time, under different conditions like different lightings, different weather and occlusion. Tesla, Waymo rely on deep neural networks for object detection.

Why DL? The input given is raw pixels, It is not possible for an engineer to write a feature for “A pedestrian who is hidden behind a parked van, in rain, at night”. Neural networks learn features in layers. Basically edges and textures are learnt in early layers, parts like wheels or limbs are learnt in middle layers and whole objects are learnt by next layers. The performance tends to keep improving because the features are learnt and the training data keeps growing and eventually covers situations that are less frequent. This scaling behavior is a defining trait of deep learning, and the course’s references on deep learning use cases (Dilmegani) and deep learning fundamentals (IBM, 2025) discuss it.

Why ML doesn’t fit? Previously there used to be hand designed features like edge detectors and gradient histograms. These might have worked in limited settings but in open road conditions they did not work. For example the same pedestrian might look different under sodium lights, in fog, in glare and from different angles. So the variations in real time are unlimited. If the feature is human written, then the human is supposed to predict all these possibilities beforehand. But a learned representation can pull all these variations easily from the input data.

Conclusion

From the above examples we can understand that the deciding factor is where the useful signal lives. If it is present in named, structured features old ML is cheaper and faster as it would be easy to retrain and easier to debug. If the signal is raw, and the data is variable deep learning justifies the cost as deep learning can learn representations which human made features cannot cover.
